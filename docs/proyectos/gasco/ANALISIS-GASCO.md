## 3. Documentos descartados

| Documento                               | Razón                                                   |
| --------------------------------------- | ------------------------------------------------------- |
| Anexos de licitación (N°1 a N°12)       | Trámites administrativos, sin contenido técnico público |
| DTEs y Ordenes de Compra (ADICIONALES/) | Documentos contables/fiscales                           |
| Memorandos internos                     | Comunicación interna                                    |
| Planilla Datos Entregable Licitaciones  | Formulario administrativo                               |
| Clave.pdf                               | Posiblemente credenciales                               |
| Archivos .rar comprimidos               | Necesitan extracción primero                            |
| ~$CRONOGRAMA (archivo temporal)         | Archivo temporal de Excel                               |

## 4. Cambios realizados en la web

### 4.1 Servicio "Tanques Especiales" — `src/content/servicios/tanques-especiales.md`

- Reemplazado Lorem ipsum con contenido real
- Agregados: tipos de tanques, aplicaciones, 5 procesos detallados
- Incluidos los dos proyectos destacados de Gasco con datos reales

### 4.2 Ficha de proyecto Coyhaique — `src/content/proyectos/tanques-glp-coyhaique.md`

- Enriquecida con datos de la oferta HDM-594/2024
- Dimensiones: Ø 2.975 mm × 14.400 mm, peso 25,1 Ton
- Materiales: ASTM A516 / ASTM A36
- Válvulas, soldadura SAW, NDT, certificación SEC

### 4.3 Ficha de proyecto Puerto Williams — `src/content/proyectos/tanques-glp-puerto-williams.md`

- Enriquecida con datos de la oferta HDM-602/2024
- Mismas especificaciones técnicas
- Condición especial: clima frío, exposición sísmica extrema

### 4.4 Galería de proyectos — `src/data/project-galleries.ts`

- Agregados slugs `tanques-glp-coyhaique` y `tanques-glp-puerto-williams`

### 4.5 Entradas CMS — `src/data/cms-content.json`

- Creadas entradas `project-gallery.tanques-glp-coyhaique` y `project-gallery.tanques-glp-puerto-williams` con 3 slots de imagen cada una
