## Criterio de actualización

- Un dato pendiente no vuelve al contenido público hasta que se agregue una fuente identificable.
- La migración del CMS modifica únicamente valores que coinciden exactamente con las versiones antiguas auditadas.
- Las futuras exportaciones deben conservar esta matriz como control editorial y ejecutar `npm run cms:migrate-audited-content -- --check` antes de publicar.
