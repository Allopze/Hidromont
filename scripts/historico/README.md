# Scripts históricos

Herramientas de despliegues y tareas anteriores (Cloudflare Pages, cPanel con
Passenger, FTP, curado inicial de fotos) que ya no se usan ni se referencian
desde el proyecto. Se conservan como referencia; no se mantienen, no pasan por
el lint y pueden no funcionar con el código actual.

El despliegue vigente es `scripts/deploy-vps.sh` (ver `docs/DESPLIEGUE-VPS.md`).
Los de `cms/scripts/historico/` son siembras puntuales de la galería que ya se
aplicaron a la base.

Archivados en la auditoría de septiembre de 2026 (P3-02).
