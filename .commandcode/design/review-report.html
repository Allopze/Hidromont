// WHAT'S WORKING

Photography as evidence

Real workshop photos, fabrication shots, dam sites. No stock, no illustrations. Directly answers "Do they actually build this stuff?"

Alternating section rhythm

Default/alt/strong sequence creates a visual drumbeat. Each dark section punctuates a new chapter. Consistent across all pages.

CMS integration is invisible

EditableText/Image wrap every field. CmsOverlay only appears for authenticated users. Design works unchanged from markdown or CMS.

Button component is thorough

Four variants, two sizes, disabled state, focus-visible outline, touch targets ≥ 44px. This is the standard every component should meet.

Fluid typography

Clamp values mean headings scale naturally across viewports. The site reads well at 375px and 1440px with the same CSS.

// PRIORITY ISSUES
P0

Dropdown navigation inaccessible on touch and keyboard

Header.astro uses CSS group-hover for "Servicios" dropdown visibility. No aria-haspopup, no aria-expanded, no keyboard handlers, no touch toggle. Submenu links sit inside opacity-0 invisible — unreachable via Tab.

FIX: Add button with aria-expanded + click/tap toggle. Keep hover as secondary. Add focus-within for tab navigation through submenu. Mode: /design interaction
P0

No loading/submitting state on contact form

Submit button has no data-loading state, no spinner, no disable-on-submit. Form uses native POST to Web3Forms — the user sees nothing between click and redirect. Risk of duplicate submissions.

FIX: On submit, disable button, swap text to "Enviando...", show inline spinner. Use fetch + FormData for client-side error handling. Mode: /design interaction
P1

Empty states disappear instead of communicating

Home page and clients page use conditional rendering with no else branch. When collections are empty, entire sections vanish — no "what belongs here" message, no guidance.

FIX: Add an EmptyState component explaining what belongs and how to fill it. Use in all conditional blocks. Mode: /design surface
P1

Dense content pages have flat typographic hierarchy

empresa.astro has 4 major content sections within one Section. All use same H2 size, same body size, same line-height. Distinction relies on grid gaps, not typography.

FIX: Introduce --font-size-lead token, increase H2-H3 scale gap, add visual treatment to subsection headings. Mode: /design typeset
P2

Card hover lift conflicts with industrial voice

ServiceCard and ProjectCard use hover:-translate-y-0.5 — a consumer/SaaS pattern. Heavy industrial equipment doesn't float up.

FIX: Remove translate-y. Use chromatic hover: border → primary, bg → primary-light, shadow deepens. Mode: /design refine
P2

Light-on-dark text lacks compensation

Dark sections use same line-height and letter-spacing as light sections. White text on #0F2433 appears optically thinner — needs more line-height, neutral tracking, adjusted weight.

FIX: Increase line-height by 0.05–0.1, set letter-spacing: 0, use weight 400 for body on dark. Mode: /design typeset
